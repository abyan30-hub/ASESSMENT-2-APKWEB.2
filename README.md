itur Utama Aplikasi (Assessment II - Lab)

Konsep OOP PHP (Hewan.php)

Menerapkan Encapsulation, Inheritance, dan Polymorphism melalui parent class Hewan serta child class Mamalia dan Burung.

Manajemen Temporary Data ($_SESSION & $_COOKIE)

Menggunakan $_SESSION untuk menyimpan daftar data hewan sementara dan catatan sesi aktif.

Menggunakan $_COOKIE untuk menyimpan preferensi tampilan (Mode Terang / Gelap) dan label penanda sementara.

Upload File & Gambar Terpisah

File gambar (jpg, jpeg, png, gif, webp) otomatis disimpan ke folder images/.

File dokumen/biasa (pdf, doc, docx, txt, csv, xlsx) otomatis disimpan ke folder files/.
